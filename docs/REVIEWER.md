# Проверка проекта

[<kbd>English version</kbd>](REVIEWER.en.md)

Этот документ помогает проверяющему быстро убедиться, что в репозитории есть исходники, документация и способ запустить продукт без сборки из исходного кода.

## Требования

- Исходный код продукта: `src/`, `manifest.json`, `styles.css`, `main.js` после production build.
- Документация пользователя: `README.md` и `README.en.md`.
- Документация для разработчиков: `docs/DEVELOPMENT.md` и `docs/DEVELOPMENT.en.md`.
- Установочник: архив `study-zen-<version>.zip` в GitHub Release или artifact `study-zen-plugin` из успешного CI run.

## Установка без сборки

Основной путь:

1. Откройте GitHub Releases проекта.
2. Скачайте последний `study-zen-<version>.zip`.
3. Распакуйте архив в `.obsidian/plugins/study-zen/` внутри тестового vault.
4. Включите Study Zen в настройках Obsidian.

Если tagged release ещё не создан:

1. Откройте вкладку Actions в GitHub.
2. Выберите последний успешный workflow `CI` для `main` или актуального PR.
3. Скачайте artifact `study-zen-plugin`.
4. Распакуйте вложенный `study-zen-<version>.zip` в `.obsidian/plugins/study-zen/`.
5. Включите Study Zen в настройках Obsidian.

## Smoke test

1. Откройте палитру команд Obsidian и запустите `Study Zen: Начать сессию`.
2. Выберите режим, цель, ожидаемый результат и длительность.
3. Проверьте экран фокуса: таймер, цель, прогресс и кнопки управления.
4. Поставьте сессию на паузу, продолжите и завершите её.
5. Откройте статистику и убедитесь, что сохранённая сессия появилась в истории.
6. В настройках Study Zen переключите язык интерфейса и проверьте, что UI обновился.
